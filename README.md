# Word 转 PPT 自动化程序 - 支持七级标题层次

## 项目概述
本工具是一个基于 Python 的自动化程序，能够将 Word 文档自动转换为 PowerPoint 文件，特别支持识别一级到七级标题层次结构，并保持正确的层级关系。

## 核心功能
- ✨ **七级标题识别**：自动识别 Word 文档中的一到七级标题
- 🎨 **智能层级判断**：优先使用样式信息，辅以字号、加粗、居中特征
- 📊 **正确内容归属**：正文内容自动归属到最近的上层标题
- 🎯 **结构清晰的 PPT**：不同层级标题在 PPT 中得到明确区分
- 💾 **自动保存**：支持自定义保存路径和默认路径保存

## 标题层次识别规则
1. **内置样式优先**：优先使用 Word 中的 Heading 1 - Heading 7 样式
2. **中文样式支持**：同时支持 "标题 1" - "标题 7" 等中文样式
3. **字号相对差异**：当样式信息不足时，根据字号大小推断层级
4. **格式特征辅助**：加粗、居中格式可辅助确认标题

## Word 到 PPT 映射规则
- 一级、二级、三级标题：作为 PPT 页面的主标题
- 四级到七级标题：作为内容区域的强调标题或副标题
- 每个标题生成一张幻灯片
- 标题下的正文内容归属于该标题页面

## 使用方法

### 1. 环境要求
- Python 3.6+
- python-docx：用于处理 Word 文档
- python-pptx：用于生成 PowerPoint 文件

### 2. 安装依赖
```bash
pip install python-docx python-pptx
```

### 3. 使用方式

#### 方式一：命令行模式
```bash
# 转换指定的 Word 文档到默认路径
python word_to_ppt.py [Word 文档路径]

# 转换并指定保存路径
python word_to_ppt.py [Word 文档路径] [PPT 保存路径]
```

#### 方式二：图形界面模式
直接运行程序会启动图形界面：
```bash
python word_to_ppt.py
```
然后按照提示选择 Word 文件和保存路径。
